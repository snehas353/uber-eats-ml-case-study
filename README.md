
# Uber Eats ML Case Study

## Day 1: Project Setup, Data Generation, and EDA

### 1. Project Setup
- Initialized the project structure and Git repository.
- Organized scripts, raw data, and processed data.

### 2. Synthetic Data Generation
Generated seven datasets:
- Customers
- Restaurants
- Drivers
- Orders
- Deliveries
- Payments
- Reviews

### 3. Data Quality Checks
- Checked dataset shapes and data types.
- Examined missing values and duplicate records.
- Validated IDs and converted date columns.

### 4. Exploratory Data Analysis (EDA)
- Analyzed order status, order amounts, and city-wise orders.
- Studied hourly and weekday ordering patterns.
- Examined delivery times, preparation times, weather, and traffic.
- Analyzed restaurant performance and customer behavior.
- Investigated payment methods, payment status, and customer reviews.

### 5. Feature Engineering
- Extracted order hour, day, and month.
- Calculated total fulfillment time.
- Categorized delivery speeds as Fast, Moderate, and Slow.

### 6. Processed Data
- Saved the merged orders and delivery dataset.
- Saved the orders dataset with time-based features.
